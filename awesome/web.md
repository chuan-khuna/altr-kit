# Awesome Web

## Interactive learning playground

- [Designed to Scale](https://designed-to-scale.vercel.app/) — An interactive course on system design.
- [Electronics 101](https://electronics-101-six.vercel.app/) — Hands-on lessons for beginners on resistors, components, circuits and circuit maths, with a 3D circuit you can rotate and switch between a diagram and a breadboard view.
- [robotips](https://robotips.app/en) — Robotics labs that show how a circuit is put together and how it works, with simulators, videos, an 8-week roadmap and a glossary.

## Team tools

- [Team Shape](https://wuttitarn.com/team-shape/) — Interactive tool by Tarn Wuttiporn that shows your team's skills and growth. Also in [Thai](https://wuttitarn.com/th/team-shape).
