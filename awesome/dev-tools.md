# Awesome Dev Tools

## Design

- [Phosphor](https://www.joshuastevens.net/phosphor/) — Free tool by Joshua Stevens for making accessible color palettes (sequential, diverging, qualitative, bivariate) built around lightness, with exports for CSS, Python, R and GIS tools.
- [glasbey — continuous colormaps](https://glasbey.readthedocs.io/en/latest/continuous_colormaps.html) — Python library for perceptually uniform color palettes. This page shows how to fit a smooth or diverging colormap through a few seed colors, limit its lightness, chroma and hue, and export it to matplotlib or as hex colors.

## Illustration & art

- [Overflow isometric](https://www.overflow.design/isometric/) — Isometric line icons and illustrations in several styles, to copy or drag into your designs. Also offered as a Figma plugin and an MCP server. Some drawings are free; Pro is paid.
- [ascii.rest](https://ascii.rest/) · [GitHub](https://github.com/bas3line/ascii) — Animated ASCII art for web pages (scenes, loaders, charts, type, shapes) with no dependencies. Use it with a script tag, a React or Astro component, a TypeScript `mount()` call, or `npx ascii.rest` in a terminal. Free (MIT).

## UI components

- [Componentry — Annotated Text](https://componentry.dev/docs/components/annotated-text) — A shadcn-style React component that draws hand-drawn marks (circle, underline, highlighter, box) around inline text and animates them in when they scroll into view. Install with `pnpm dlx shadcn@latest add @componentry/annotated-text`.
- [Rough Notation](https://roughnotation.com/) · [GitHub](https://github.com/rough-stuff/rough-notation) — Small JavaScript library that animates hand-drawn marks on a page: underline, box, circle, highlight, strike-through, crossed-off and bracket. Free (MIT).
- [mdxcn](https://www.mdxcn.dev/) · [GitHub](https://github.com/shadcn-labs/mdxcn) — Graphs and diagrams drawn in text, for people and agents to put in writing. In MDX they render as React components; in READMEs and PRs you paste them as ASCII blocks. Install with `pnpm dlx shadcn@latest add https://mdxcn.dev/r/all.json`.
- [Driver.js](https://driverjs.com/) · [GitHub](https://github.com/kamranahmedse/driver.js) — Small, dependency-free JavaScript library for product tours, step-by-step guides and highlighting elements on a page. Free (MIT).
- [Bencho](https://bencho.dev/) — Library of React components and micro-interactions (confetti, dock, toast stack and more) that you copy into your project. Some blocks are free; the rest need a paid Pro plan.

## Frameworks

- [Effect](https://effect.website/) · [GitHub](https://github.com/Effect-TS/effect) — TypeScript library for writing apps with typed errors, dependency injection, concurrency, retries and resource handling, plus a standard library (schema, streams, HTTP) built on the same model.

## Sound

- [UI SFX](https://uisfx.com/) · [GitHub](https://github.com/romainsimon/uisfx) — Hundreds of interface sound effects (success, error, click and other UI cues) in several styles. On the web, `npm install uisfx` plays them live with `ui.play('success')`; anywhere else, copy the MP3 or Ogg files. Free: code is MIT, sounds are CC0.
- [Foley](https://usefoley.dev/#playground) · [GitHub](https://github.com/eakbulut/foley) — JavaScript library of UI sound effects made live with Web Audio, so there are no audio files to ship. Install with `npm install @foleyjs/core`; React and Vue versions too. Free (MIT).
